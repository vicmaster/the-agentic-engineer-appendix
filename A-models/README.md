# Appendix A — Model Landscape

Where the body says *a frontier hosted model* or *a current model*, this section names which one, when, and what its load-bearing properties were at the time.

## What lives here

- Frontier model names and versions (current as of the entry's `Last reviewed` date).
- Default output ceilings — the numbers that motivate Ch. 3's *budget-the-headroom-you'll-never-use* discipline.
- Context window sizes and pricing structure context.
- Capability differences that affect agentic patterns (tool-use support, vision, streaming behavior, structured output).
- Known model-specific quirks the book points at.

## What doesn't live here

- Marketing comparisons. The appendix is descriptive, not evaluative.
- Predictions about future models. The body explicitly opts out of "future of work" framing; this appendix sticks to what was true on the day the entry was written.
- Per-provider SDK code — that's in `B-sdks/`.

## Organization

One entry per provider per major model family, with a `_current.md` symlink or pointer convention as the lineup turns over.
