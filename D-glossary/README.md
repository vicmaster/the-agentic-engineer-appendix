# Appendix D — Glossary

The glossary holds the canonical, slightly-tighter-than-casual definitions for terms the book uses repeatedly. Each chapter italicizes a term on first use and gives a working definition inline; the entry here is the durable version, written to survive vocabulary drift in the wider field.

## Conventions

- One file per term, named after the term in kebab-case.
- Each entry leads with a one-line definition (the "if I had to fit it on a card" version), then expands.
- Each entry names the chapter where the term is first introduced and the chapters where it is load-bearing.
- Where the field uses the term loosely, the entry says how *this book* uses it and what it deliberately excludes.
- Entries are dated; revise as the field's usage shifts.

## How chapters link here

Chapters do not cross-reference glossary entries by URL — the book stays portable. Italicized first uses in the body and a pointer to "appendix D" is the contract. The reader finds the entry by term name; the glossary keeps the entry findable.
